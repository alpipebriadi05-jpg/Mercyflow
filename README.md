# Mercyflow

> Give with clarity. Create lasting impact.

Mercyflow is a transparent platform connecting compassion with meaningful action, built to make every contribution create a lasting impact.

## MVP
A responsive React/Vite landing page that forms the foundation for future campaigns, transparency tools, wallets, and blockchain verification.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

## Product direction

Community → Mercyflow → Campaigns / Contributions → Transparent records → Wallet infrastructure → Blockchain verification → Measurable impact

Mercyflow intentionally starts with the product experience before introducing token mechanics.

## Structure

- src/components/ — reusable UI components
- src/pages/ — application pages
- src/services/ — API, wallet, and blockchain integration layer
- src/config/ — network and project configuration
- src/hooks/ — reusable React hooks
- src/utils/ — formatting and helper utilities
- database/ — database schema and seed data
- contracts/ — future smart-contract layer
- docs/ — product vision, tokenomics, and roadmap
